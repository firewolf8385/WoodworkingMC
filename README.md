WoodworkingMC is a quality of life datapack for Minecraft 26.1.2 that adds over **700** more crafting recipes related to wooden blocks to make building with wood more enjoyable.

## Stonecutter Recipes
![Oak Log in stonecutter](https://cdn.modrinth.com/data/cached_images/3ff08dadd8002397e45f87c71bc47c3b6e1bebc3.png)

Wooden blocks can now be used in the stone cutter, to make crafting more efficient. You can strip logs, bulk craft stairs and slabs, and even craft more complicated blocks like fences and signs.

## Bulk Craft Chests
![Chest recipes](https://cdn.modrinth.com/data/In8sDfRr/images/93c47edeef5c3849af80e192d1c9460482a40ce6.gif)

This datapack also makes crafting chests easier by adding chest recipes using logs instead of planks. It still takes 8 planks per chest, but you no longer need to break the log into planks first.
